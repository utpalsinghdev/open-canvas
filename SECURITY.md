# Security policy

## Report a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/utpalsinghdev/open-canvas/security/advisories/new) to report a suspected vulnerability. Do not post suspected vulnerabilities in public issues or discussions.

Include the following when available:

- The Open Canvas version or commit, your operating system, and the affected component.
- Steps to reproduce the issue with disposable data.
- What an attacker could access or change, and the conditions needed for that to happen.
- Any known workaround.

Remove credentials, browser tickets, and private workspace data from logs and attachments. Keep the details private while we investigate and coordinate disclosure.

## Supported versions

Security fixes target the [latest stable release](https://github.com/utpalsinghdev/open-canvas/releases/latest). If you can safely test on that version, tell us whether the issue still occurs. You can report a suspected vulnerability even if you cannot retest it.
